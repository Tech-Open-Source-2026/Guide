# Kami Academic Korean Lecture

따뜻한 종이색 본문과 잉크 블루 표지·요약을 사용하는 한국어 대학 강의용 Kami 변형이다.

## 원칙

- `X주차_배포용.md`의 `##` 하나를 HTML 장표 하나로 보존한다.
- 학생 화면에는 배포 방식, 템플릿명, 생성 도구, 파일 경로를 표시하지 않는다.
- 제목은 명조 500, 본문은 고딕 22–28px, 숫자는 tabular-nums를 사용한다.
- 잉크 블루 외의 채도 높은 강조색, 이탤릭, 그라디언트, 글래스모피즘을 사용하지 않는다.
- 코드·표·그림은 원본 장 안에서 유지하고 입력·비교 기준·확인 결과를 함께 보여 준다.
- 1920×1080 캔버스, 키보드·휠·터치 이동, ESC 개요, localStorage, print CSS를 제공한다.

## 출처

내용의 유일한 원본은 같은 주차의 `X주차_배포용.md`와 그 문서가 참조한 `images/`이다.
