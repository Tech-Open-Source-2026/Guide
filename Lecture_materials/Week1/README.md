# Week 1 — 강의계획과 Git 기초

강의 슬라이드는 [`index.html`](./index.html)을 브라우저로 열면 바로 실행된다.

## 강의 조작

- `전체화면` 버튼 또는 `F`: 전체화면 시작·종료
- `Esc`: 전체화면 종료 또는 열린 장표 개요 닫기
- `←` `→`, `Page Up` `Page Down`, `Space`: 장표 이동
- `Home` `End`: 첫 장·마지막 장 이동
- `O`: 전체 장표 개요 열기·닫기

브라우저 보안 정책 때문에 페이지가 사용자 입력 없이 자동으로 전체화면을 시작할 수는 없다. 첫 화면에서 `전체화면` 버튼을 한 번 누르면 된다.
