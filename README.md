# Open소스프로그래밍 강의자료

## 1주차

- [전체화면 강의 슬라이드](https://tech-open-source-2026.github.io/Guide/Lecture_materials/Week1/)

슬라이드를 연 뒤 `전체화면` 버튼 또는 `F` 키를 누르면 전체화면 강의를 시작할 수 있습니다.

- 다음 장: `→`, `↓`, `Page Down`, `Space`
- 이전 장: `←`, `↑`, `Page Up`
- 처음·마지막 장: `Home`, `End`
- 전체 장표 개요: `O`
- 전체화면 또는 개요 닫기: `Esc`
- 현재 장표는 브라우저에 자동 저장됩니다.
