# 데이터시각화 강의자료

## 1주차

- [전체화면 강의 슬라이드](https://tech-open-source-2026.github.io/Guide/Lecture_materials/Week1/)

슬라이드를 연 뒤 화면 오른쪽 위의 `전체 화면` 버튼이나 `F` 키를 누르면 전체화면 강의를 시작할 수 있습니다.

- 다음 장: `→`, `↓`, `Page Down`, `Space`
- 이전 장: `←`, `↑`, `Page Up`
- 처음/마지막 장: `Home`, `End`
- 전체 슬라이드 보기: `Esc` (`Esc`는 전체화면 상태에서는 먼저 전체화면을 종료합니다.)
- 현재 슬라이드는 브라우저에 자동 저장됩니다.
