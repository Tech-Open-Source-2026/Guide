# Open소스프로그래밍 강의자료

## 온라인 강의자료

- [주차별 강의자료 바로 열기](https://tech-open-source-2026.github.io/Guide/)

첫 화면에서 주차를 선택한 뒤 `강의 시작`을 누르면 발표 덱이 열립니다. 주차 선택 화면으로 돌아갈 때는 브라우저의 뒤로 가기를 사용합니다.

현재 공개 범위는 1–2주차입니다.

## 강의 화면 조작

슬라이드를 연 뒤 `F` 키를 누르면 전체화면 강의를 시작할 수 있습니다.

- 다음 장: `→`, `↓`, `Page Down`, `Space`
- 이전 장: `←`, `↑`, `Page Up`
- 처음·마지막 장: `Home`, `End`
- 전체 장표 개요: `O`
- 전체화면 또는 개요 닫기: `Esc`
- 현재 장표는 브라우저에 자동 저장됩니다.
