## 강의 화면 조작

1–4주차 슬라이드를 연 뒤 `F` 키를 누르면 전체화면 강의를 시작할 수 있습니다.

- 다음 장: `→`, `↓`, `Page Down`, `Space`
- 이전 장: `←`, `↑`, `Page Up`
- 처음·마지막 장: `Home`, `End`
- 전체 장표 개요: 1–4주차는 `O`, 5주차는 `Esc`
- 전체화면 또는 개요 닫기: `Esc`
- 5주차의 전체화면은 브라우저의 전체화면 기능을 사용합니다.
- 현재 장표는 브라우저에 자동 저장됩니다.
